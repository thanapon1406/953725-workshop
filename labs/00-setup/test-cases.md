# Test case ของระบบเลือกตั้ง — ส่วนที่รับผิดชอบ: voter

> 10 กรณี ครอบคลุม flow การทำงานของผู้มีสิทธิ์: ลงทะเบียน → login → ลงคะแนน/เปลี่ยนคะแนน → ดูรายชื่อผู้สมัคร

## [1] การลงทะเบียน (เฉพาะ role: voter)

| ID | Given | When | Then |
|---|---|---|---|
| TC-01 | ผู้มีสิทธิในเขต CM-1 ที่ยังไม่เคยลงทะเบียน | ลงทะเบียนด้วยเลขบัตรที่จำนวนของบัตรประชาขนเกิน 13 หลัก | ระบบปฏิเสธด้วย 400 และไม่สร้างบัญชี |
| TC-02 | ผู้มีสิทธิในเขต CM-1 | ลงทะเบียนด้วยรหัสผ่านสั้นกว่า 8 ตัวอักษร | ระบบปฏิเสธด้วย 400 และไม่สร้างบัญชี |
| TC-03 | ผู้มีสิทธิในเขต CM-1 | ลงทะเบียนด้วยเขตเลือกตั้งที่ไม่มีในระบบ | ระบบปฏิเสธด้วย 400 และไม่สร้างบัญชี |
| TC-04 | ผู้มีสิทธิในเขต CM-1 | ลงทะเบียนสำเร็จด้วยข้อมูลครบถ้วน | ระบบสร้างบัญชีและส่งสิทธิ์ token กลับ |

## [2] การเข้าสู่ระบบ (auth ของ voter)

| ID | Given | When | Then |
|---|---|---|---|
| TC-05 | ผู้ใช้ที่ไม่เคยลงทะเบียน | login ด้วยเลขบัตรที่ไม่เคยเก็บ | ระบบปฏิเสธด้วย 401 |
| TC-06 | ผู้มีสิทธิในเขต CM-1 ที่ยืนยันตัวตน | login ด้วยเลขบัตร + รหัสผ่านถูกต้อง | ระบบส่ง JWT กลับมา |
| TC-07 | ผู้ใช้ที่ยืนยันตัวตนแล้ว | เรียก API ลงคะแนน โดยไม่มี Authorization ที่อยู่ใน header | ระบบปฏิเสธด้วย 401 |

## [3] การลงคะแนนและเปลี่ยนคะแนนของ voter

| ID | Given | When | Then |
|---|---|---|---|
| TC-08 | ผู้มีสิทธิในเขต CM-1 ที่ยังไม่เคยลงคะแนน | ลงคะแนนให้ผู้สมัครหมายเลข 2 ของเขต CM-1 | ระบบบันทึกคะแนน และแสดงว่าเลือกหมายเลข 2 แล้ว |
| TC-09 | ผู้มีสิทธิที่เลือกหมายเลข 2 ไปแล้ว | เปลี่ยนคะแนนเป็นหมายเลข 3 | ระบบอัปเดตเป็นหมายเลข 3 และไม่นับหมายเลข 2 ซ้ำอีก |
| TC-10 | ผู้มีสิทธิในเขต CM-1 | ลงคะแนนให้ผู้สมัครของเขต CM-2 | ระบบปฏิเสธ เพราะไม่ใช่ผู้สมัครในเขตของตัวเอง |
